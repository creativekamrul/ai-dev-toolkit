# Contributing

Start with one useful resource and a real use case. Search the catalog and import-candidate
report before introducing overlap. Keep skill descriptions precise and put long conditional
reference material in linked files.

Record provenance, license evidence, dependencies and review status. Preserve attribution and
original installations. Never publish the local inventory, staging copies or auth settings.
Use explicit file allowlists and hashes. See `docs/MAINTENANCE.md` for the import process.

Run `python scripts/validate.py` and `python -m unittest discover -s tests -v` before review.
Report runtime compatibility separately from file-format and layout validation. Do not add
hundreds of placeholder skills or claim support for presets that have not been implemented.
