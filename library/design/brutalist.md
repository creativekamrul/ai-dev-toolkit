# Design contract: Brutalist / bold

Use emphatic type, visible borders, direct layout and confident contrast. Rawness is intentional styling, not broken spacing or inaccessible controls. Keep predictable navigation and readable text. Avoid adding heavy dependencies for a simple visual effect.

The Designer records concrete tokens, layout, responsive rules and component states for this project. Respect user-supplied references and existing constraints. Validate actual rendered output when a UI exists.
