# Design contract: Funky / playful

Use expressive typography, lively color, playful composition and deliberate asymmetry. Choose a coherent visual motif instead of unrelated decoration. Keep reading order, interaction affordances and content contrast clear. Motion can add personality but must respect reduced-motion settings.

The Designer records concrete tokens, layout, responsive rules and component states for this project. Respect user-supplied references and existing constraints. Validate actual rendered output when a UI exists.
