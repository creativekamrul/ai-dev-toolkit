# Design contract: Glassmorphism

Use translucent layered surfaces, background blur, subtle borders and depth intentionally. Define a readable opaque fallback when backdrop filters are unavailable. Test actual contrast over both light and dark backgrounds. Limit blur layers for performance and keep text/buttons legible without relying on transparency.

The Designer records concrete tokens, layout, responsive rules and component states for this project. Respect user-supplied references and existing constraints. Validate actual rendered output when a UI exists.
