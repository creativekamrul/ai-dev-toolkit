# Professional business UI

Inspect the existing product, components, tokens, content density and key user journey first.
Preserve a coherent existing identity. For a new interface, choose a neutral surface palette,
one functional accent and a readable type family. Explain any departure required by the brief.

Establish a small type scale, spacing scale, border treatment and component state vocabulary.
Use consistent alignment, clear page titles, visible primary actions and readable secondary text.
Favor solid surfaces and modest radii. Gradients, glow, glass, decorative shapes, heavy shadows
and elaborate animation need a concrete purpose; they are not defaults.

Use the relevant layout decisions:

- Dashboards, CRM and admin: prioritize the daily task, make filters and selection visible,
  align comparable numbers and preserve useful table density without shrinking text.
- Business and landing pages: lead with a specific value proposition, credible evidence and
  a clear next action. Avoid repeated decorative sections without useful content.
- Commerce: make price, variants, availability and total cost legible; preserve cart state
  and show actionable form errors.
- Mobile: prioritize content and primary actions; adapt navigation and wide data views
  without hiding essential functionality or causing page-level horizontal overflow.
- Design systems: reuse semantic tokens and existing components before adding variants;
  document the behavioral difference that justifies a new variant.

Define loading, empty, error, success, disabled, hover and keyboard-focus states where applicable.
Use semantic controls with labels, keyboard access and visible focus. Verify contrast and zoom;
do not rely on color alone. Honor reduced-motion preferences and maintain logical focus order.

Inspect rendered output at a narrow viewport and a representative desktop width. Check long
labels, realistic data, text wrapping, overflow and keyboard traversal. Report what was actually
rendered or tested and any remaining gaps. Use real products as quality references without
copying branding or assuming their interaction patterns fit this task.
